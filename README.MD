# Rocket Fi 🚀

**Secure, Client-Side, AI-Powered Retirement Planning.**

Rocket Fi is a modern web application designed to help users plan for financial independence and retirement without compromising their privacy. Unlike traditional financial tools, Rocket Fi operates entirely in your browser—no databases, no server-side storage of financial data, and military-grade encryption for your local files.

## 🌟 Key Features

### 🔒 Privacy-First Architecture

- **Zero-Knowledge Storage:** All data is stored in your browser's `LocalStorage`.
- **Client-Side Encryption:** User profiles are protected via AES encryption. We do not have the keys to your data.
- **Data Portability:** Export your entire financial profile to encrypted JSON for backup or transfer.

### 📊 Comprehensive Financial Dashboard

- **Aggregated View:** Track Investments, Assets, Liabilities, Income, and Expenses in one place.
- **Real-time Calculations:** Instant updates to Net Worth and Monthly Surplus/Deficit.
- **Smart Categorization:** Tag items for Pre-Retirement, Post-Retirement, or specific tax advantages.

### 🎯 Retirement Goals & Modeling

- **Lifecycle Modeling:** Separate projections for Pre-Retirement accumulation and Post-Retirement decumulation phases.
- **3-Bucket Strategy:** Visualizes liquidity, stability, and growth allocations.
- **Inflation Adjustment:** Global settings to model purchasing power over time.

### 🤖 AI Agent Integration

- **Personalized Insights:** Connects to **OpenRouter.ai** to analyze your anonymized financial snapshot.
- **Agentic Analysis:** Generates actionable strategies (e.g., tax optimization, risk rebalancing) using models like `google/gemma-3-27b-it`.
- **Prompt Transparency:** Review exactly what data and prompts are sent to the AI before submission.

### 🎲 Advanced Simulations

- **Monte Carlo Analysis:** Run thousands of scenarios to test the probability of success.
- **Risk Metrics:** View Sharpe Ratio, Sortino Ratio, and Maximum Drawdown analysis.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

1.  **Clone the repository**

    ```bash
    git clone [https://github.com/yourusername/rocket-fi.git](https://github.com/yourusername/rocket-fi.git)
    cd rocket-fi
    ```

2.  **Install dependencies**

    ```bash
    npm install
    ```

3.  **Environment Setup**
    Create a `.env` file in the root directory:

    ```env
    VITE_OPENROUTER_API_KEY=your_api_key_here
    VITE_APP_NAME="Rocket Fi"
    ```

4.  **Run the Development Server**

    ```bash
    npm run dev
    ```

5.  **Build for Production**
    ```bash
    npm run build
    ```

## 🔐 Security & Data Handling

### How we keep your data safe:

1.  **Local Only:** Rocket Fi does not have a backend database for user data. Everything lives in your browser.
2.  **Encryption:** When you create a profile, you set a password. This password generates an encryption key used to lock your data in `LocalStorage`. If you lose this password, your data cannot be recovered by us.
3.  **AI Privacy:** When using the "AI Analysis" feature, we strip personally identifiable information (Name, Email, Address) before sending financial aggregates to the LLM. You can review the raw prompt payload before it leaves your browser.
